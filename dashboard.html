⚙️ Configuración

Tu API key de Groq está segura en el servidor (.env), nunca se expone al navegador.

GROQ_API_KEY=gsk_tu_clave_aqui PORT=3000 NODE_ENV=development

Para cambiar la clave:

  1. Obtén una nueva clave en console.groq.com
  2. Edita el archivo .env
  3. Reinicia: npm start

🎮 Cómo Usar

  1. Abre el Builder
  2. Escribe un prompt: "Landing de cafetería con tema oscuro"
  3. ¡La IA generará la página automáticamente!
  4. Ajusta en tiempo real con nuevos prompts
  5. Descarga o comparte el resultado
